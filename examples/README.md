# examples

Demo agents that talk to Razorpay through the firewall.

- [`support-agent/`](support-agent/README.md) — a customer-support agent (Claude Agent SDK) that handles tickets and
  issues refunds, against the firewall or Razorpay directly (T015). Also holds the test-payment seeding and the
  `verify-live` check of the live Razorpay MCP server.
